# Reports Directory

This directory stores PDF reports generated by the Sample Size Calculator application.

## Directory Structure

```
reports/
├── validation/     # IQ/OQ/PQ validation certificates
├── calculations/   # Sample size calculation reports
└── full/          # Comprehensive full reports
```

## Subdirectories

### validation/
Stores Installation Qualification (IQ), Operational Qualification (OQ), and Performance Qualification (PQ) certificates generated by the automated validation test suite.

**Requirements**: 30.1

**File naming convention**: `validation_certificate_YYYYMMDD_HHMMSS.pdf`

### calculations/
Stores sample size calculation reports for both Module A (attribute data) and Module V (variable data) analyses.

**Requirements**: 27.1

**File naming convention**: `calculation_report_YYYYMMDD_HHMMSS.pdf`

### full/
Stores comprehensive reports that include complete analysis details, all intermediate calculations, and full audit trail information.

**File naming convention**: `full_report_YYYYMMDD_HHMMSS.pdf`

## File Naming Convention

All reports use timestamp-based naming with the format:
- Date: YYYYMMDD (e.g., 20240315)
- Time: HHMMSS (e.g., 143022)

Example: `calculation_report_20240315_143022.pdf`

This ensures:
- Chronological sorting
- No filename conflicts
- Easy identification of report generation time
- Compliance with QMS audit trail requirements

## Volume Mounting

This directory is mounted as a Docker volume in the docker-compose.yml configuration:
```yaml
volumes:
  - ./reports:/app/reports
```

This ensures report persistence across container restarts and allows easy access to generated reports from the host system.

## Permissions

The application requires read/write permissions to all subdirectories for report generation. The Docker container runs with appropriate permissions to create and write PDF files.
